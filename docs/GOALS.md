# Goals

## Primary Goal
Build a trustworthy Autonomous Growth OS that can operate the majority of a business's digital growth workflow with minimal human intervention.

## Product Goals
- Be usable by non-technical users.
- Run continuously without manual prompting.
- Optimize business outcomes, not vanity metrics.
- Keep all important actions auditable.
- Use real source data for reporting.
- Learn from measured outcomes.
- Remain provider-independent where practical.
- Support multi-tenant SaaS from day one.
- Keep dangerous/high-impact actions approval-gated.

## Development Workflow Goal
Eliminate manual copy/paste between ChatGPT and Codex.

Target workflow:
`Product discussion -> structured project task -> Codex implementation -> tests -> draft PR -> review`

GitHub/project files are the source of truth, not chat history.

## Non-Goals for V1
- Fully autonomous paid advertising spend.
- Autonomous destructive changes.
- Mass backlink generation.
- Spam outreach.
- Black-hat SEO.
- Unverified AI claims presented as facts.
- MiroFish-style strategy simulation as a core dependency.
- Voice sales automation as a core dependency.
