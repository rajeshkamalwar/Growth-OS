# V1 Scope

## Objective
Prove that one customer can connect a website and core data sources, receive continuous monitoring, allow safe autonomous actions, and get a truthful daily report.

## Included
- Multi-tenant workspace foundation, authentication/basic roles, site onboarding, connector status, autonomy settings.
- Google Search Console, GA4, website crawler, basic SERP tracking, daily metric snapshots.
- SEO technical audit, metadata/internal-link opportunities, content decay and keyword/page opportunity detection, low-risk autonomous updates behind policy controls.
- Basic GEO tracked prompts, brand/competitor mentions, citation/source capture where available, visibility reporting.
- At least one production social integration, planning, draft generation, scheduling/publishing behind policy, performance ingestion.
- Backlink monitoring, prospect discovery and outreach drafting; no high-volume autonomous outreach by default.
- Daily evidence-backed report: changes, agent actions, approvals, next actions and provenance.
- Control plane: risk levels, approval queue, action ledger, idempotency keys, pause/kill switch, cost limits and audit log.

- Autonomous ad spend
- Voice agents
- MiroFish-style simulation
- Large-scale automated PR

- Full agency white-labeling
